# 🚗 City Drive – Open World Driving Experience

City Drive is a browser-based car driving game built using HTML, CSS, and JavaScript. Players can freely explore a dynamic city environment with smooth vehicle controls, realistic movement mechanics, and interactive surroundings. The game offers an engaging open-world driving experience directly in the browser without requiring any downloads or installations.

Navigate through city streets, parks, and urban areas while enjoying responsive controls and fluid gameplay. The game includes a modern HUD featuring a speedometer and minimap, providing useful driving information in real time. Advanced JavaScript logic handles vehicle physics, camera tracking, collision detection, and environment generation to create an immersive driving simulation.

Whether you want to cruise around the city, test your driving skills, or explore the environment, City Drive delivers a fun and interactive experience powered entirely by web technologies.

## Features

- Smooth and responsive car controls
- Open-world city exploration
- Real-time speedometer display
- Interactive minimap navigation
- Dynamic camera tracking system
- Realistic vehicle movement and physics
- Collision detection system
- Modern and clean user interface
- Lightweight and browser-friendly
- No installation required

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Controls

- W / ↑ Arrow Key – Accelerate
- S / ↓ Arrow Key – Brake / Reverse
- A / ← Arrow Key – Turn Left
- D / → Arrow Key – Turn Right

## Purpose

This project demonstrates the use of HTML5 Canvas and JavaScript to create an interactive open-world driving game with smooth gameplay, realistic controls, and an engaging user experience.
